# hcom Handoff Template

Use this shape for concise area handoffs.

```text
Role: <sender role>
Task: <short task name>
Status: <planned | in-progress | ready-for-review | blocked | complete>
Memory: <memory key/link/summary if available>
Bundle: <hcom bundle id if available>
Scope: <owned area and paths>
Changed files: <files or "none yet">
Checks: <commands run or requested>
Suggested commit: <Conventional Commit message or "n/a">
Open questions: <specific blockers or "none">

Request:
<what the recipient should do next>
```
